## Visual Grammar To Reuse

- The map is a clean political diagram, not a detailed provider map.
- Seas and rivers use one saturated blue family.
- States are large flat color fields with dark borders.
- The current year/date is always obvious, usually in a small top badge or title.
- The legend stays in one predictable corner and is not removed between scenes.
- City names are drawn by the project, not inherited from the basemap.
- Movement graphics are thin, readable, and limited to the current action.
- Round commander/emblem markers stay beside the active event, not in unrelated UI space.
- The camera usually holds one event in the center and changes framing smoothly.

## Rules Added From This Reference

- A commander marker belongs to a route/node, not to a decorative corner.
- If two commanders are part of the same story beat, place them on opposite sides of the contested node.
- For a tiny route, use `MACRO`; for operational movement, use `MED` or `CLOSE`.
- Prefer one active arrow per beat; old arrows fade before the next beat begins.
- Do not let symbol offsets be map-space offsets. Put them in stable local anchors so zoom never multiplies the offset.
